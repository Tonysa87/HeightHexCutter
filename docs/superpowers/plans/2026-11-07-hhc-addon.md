# HHC Add-on Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Blender 5.2 extension that turns a material asset, a scene material or a set of image files into a new, tidy `<name>_HHC` material built on the `HHC Anti-Tile` node.

**Architecture:** One package `height_hex_cutter/` at the repository root. Pure-Python modules (file-name channel detection, uniformity test on pixel arrays) are unit-tested in WSL with `unittest`. Everything touching `bpy` is tested inside the user's open Blender through the existing MCP bridge (`tools/bmcp.sh`), by a small test runner that refuses to run outside the dedicated test file. Node-group code moves from `nodes/` into the package and becomes its only copy.

**Tech Stack:** Python 3.11 (Blender's), `bpy`, `numpy` (bundled with Blender), Blender 5.2 extension manifest; WSL Python 3 + `unittest` + PIL for unit tests and fixture images.

**Spec:** `docs/superpowers/specs/2026-11-07-hhc-addon-design.md` — read it before any task.

## Global Constraints

- Blender ≥ 5.2; extension id `height_hex_cutter`, name "Height Hex Cutter", version `0.5.0`, maintainer Tonysa87, licence `SPDX:GPL-3.0-or-later`.
- Main node group name: **`HHC Anti-Tile`**; version stamp property `hhc_version` (int) on the group; current value `HHC_GROUP_VERSION = 1`.
- New material name: `<source or typed name>_HHC`. The source material is never modified.
- Displacement: only with a real Height map → Displacement node (Scale from source or `0.02`, Midlevel `0.5`), material `displacement_method = 'BUMP'`. No Height map → no Displacement/Bump node.
- Node defaults: Projection `Object`, Scale 1, Cell Size 1, Rotation 1, Seed 0, Height Influence 1.5, Softness 0.005, Normal Strength 1, Edge Warp 1.0, Sharpness 4, Space `Object`, Normal Map `OpenGL`.
- Height fallback order: Height → AO → Base Color (RGB to BW → Color Ramp, label `Height from Base Color (adjust)`) → none.
- Uniform map: every pixel within `1/255` of the mean, per used channel.
- All text (UI, reports, labels, comments, file names, commit messages) in English. No Claude attribution in commits. Commits authored as Tonysa87 (the repo's git config already is).
- Never run anything in Blender without the user's go-ahead for that session; tests run only in the user's empty test file `HHC.blend`, never in `anti-tile1.blend`.
- Cost: the HHC node must not be measurably heavier than the v0.5 `AT Anti-Tile` (Cycles ms/sample and EEVEE compile within run-to-run spread).

## Review Focus

1. **Source material is shared with other objects or materials** — converting must not change it (colour spaces, links, values). Pinned by `test_source_material_untouched` (Task 6) and the runner's global fingerprint check (Task 1).
2. **Running the converter twice on the same source** — second run gives `<name>_HHC.001`, reuses the same `HHC Anti-Tile` group, loads no image twice. Pinned by `test_convert_twice` (Task 5).
3. **Image names without a recognisable suffix or with misleading tokens** (`rock_4k.png`, `T_Bark_D.png` = DirectX? no: diffuse) — unknown files are ignored and reported, not guessed. Pinned by `test_detect_ambiguous` (Task 2).
4. **File already containing an older or foreign `HHC Anti-Tile`** — older stamped group is safely rebuilt keeping its users wired; an unstamped group is left alone. Pinned by `test_group_versioning` (Task 1).
5. **Active object that is not a mesh, or nothing selected** — operator cancels with an error and creates nothing. Pinned by `test_no_valid_object` (Task 7).

## File Structure

```
height_hex_cutter/                 the extension (zip root)
  blender_manifest.toml
  __init__.py                      register()/unregister(), wires ui.py
  channels.py                      PURE: detect_channel(filename) -> (channel, is_dx)
  uniform.py                       PURE: uniform_value(arr, tol) ; BPY: image_constant(img, chan)
  mapset.py                        PURE dataclasses MapRef / MapSet (+ summary())
  collect.py                       BPY: from_files(paths) / from_material(mat) -> MapSet
  build.py                         BPY: build_material(ms, base_name) / assign_to_object(ob, mat)
  groups.py                        BPY: ensure_group() -> NodeTree (version stamp, safe rebuild, dedupe)
  ui.py                            operators, N panel, Asset Browser context-menu entry
  nodes/
    __init__.py
    ngkit.py                       moved from nodes/ngkit.py (unchanged API)
    hexcore.py                     hex_core() moved from nodes/build_v1.py
    tile.py                        build_tile() moved from nodes/build_v3.py, renamed + changes
tests/
  unit/test_channels.py, unit/test_uniform.py, unit/test_mapset.py     (WSL: python3 -m unittest)
  fixtures/make_sets.py            PIL generator of tiny texture sets -> tests/fixtures/sets/ (gitignored)
  blender/runner.py                discovers test_* in tests/blender/, runs inside Blender, returns dict
  blender/test_groups.py, test_files.py, test_build.py, test_material.py, test_ui.py, test_cost.py
tools/hhc_test.sh                  runs tests/blender/runner.py in the open Blender via bmcp.sh
build.py                           zips height_hex_cutter/ -> dist/height_hex_cutter-<version>.zip
```

Removed at the end (Task 8): `nodes/` (history kept at tag `v0.5`). `bench/` keeps only timing/metrics code, ported to HHC names.

### Task 3: Uniform-map test and the MapSet model

**Interfaces:**
- Produces:
